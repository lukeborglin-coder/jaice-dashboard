## Main Navigation

### Home

**Intended Use:**
The Home tab serves as your personal dashboard and landing page after login. It provides a high-level overview of your active projects, tasks, and priorities.

**How to Use:**
1. **View Your Week at a Glance**: See tasks assigned to you that are due this week
2. **Review Active Projects**: Browse a vertical list of active projects ordered by priority
3. **Check Project Status**: View project phases, timelines, and priority indicators
4. **Navigate to Projects**: Click on any project card to navigate to its detailed Project Hub view
5. **Filter Projects**: Use the "My Projects Only" toggle to filter projects you're assigned to

**Key Features:**
- Priority-based project sorting (Reporting > Fielding > Pre-Field > Closed)
- Visual priority badges (Green = low, Yellow = watch, Red = urgent)
- Quick access to overdue tasks and help requests
- Project timeline previews

---

### Project Hub

**Intended Use:**
Project Hub is the central workspace for managing individual projects. It provides a comprehensive view of project details, timelines, tasks, files, and team collaboration.

**How to Use:**
1. **View Project List**: Browse active or archived projects
2. **Select a Project**: Click on a project to view its detailed dashboard
3. **Project Dashboard Tabs**:
   - **Dashboard**: Overview of project status, phases, and key information
   - **Project Files**: Organized file folders by tool (Transcripts, Content Analysis, Data Tabulation, Other Files)
   - **Timeline**: Visual week-based timeline showing project phases and deadlines
   - **Project Details**: Summary of project metadata, objectives, and background
4. **Manage Project Tasks**: View, assign, and track tasks across project phases
5. **Upload Files**: Add project-related documents and files
6. **View Timeline**: See project phases displayed across weeks with color-coded bars
7. **Team Collaboration**: View team members, assignees, and project comments

**Key Features:**
- Interactive timeline with phase visualization
- File organization by tool type
- Task management with assignment and due dates
- Project metadata and objectives display
- Integration with other tools (Content Analysis, Transcripts, etc.)

---

### Vendor Library

**Intended Use:**
Vendor Library is a centralized database for managing external vendors, moderators, and analytics providers. It helps track contact information, specialties, past projects, and availability.

**How to Use:**
1. **Navigate to Vendor Library**: Click "Vendor Library" in the main navigation
2. **Select a Section**:
   - **Moderators**: View and manage qualitative research moderators
   - **Sample Vendors**: Manage sample providers and recruitment vendors
   - **Analytics**: Track analytics and data processing vendors
3. **View Vendor Details**: Click on a vendor card to see:
   - Contact information (name, email, phone, company)
   - Specialties and areas of expertise
   - Past projects and booking history
   - Internal team notes
   - Active project bookings
4. **Add New Vendor**: Click "Add Vendor" to create a new vendor entry
5. **Edit Vendor Information**: Click the edit icon to update vendor details
6. **Schedule Management**: View moderator availability and project bookings
7. **Check Conflicts**: Use the calendar view to identify scheduling conflicts
8. **Filter Projects**: Toggle between active and archived projects for each vendor

**Key Features:**
- Vendor contact management
- Specialty tracking
- Project booking and scheduling
- Conflict detection for moderators
- Calendar view for availability
- Internal notes and team collaboration

## Qualitative Tools

### Content Analysis

**Intended Use:**
Content Analysis is an AI-powered tool for analyzing qualitative research transcripts. It helps extract key findings, themes, and insights from discussion guides and interview transcripts.

**How to Use:**
1. **Select a Project**: Choose a project from the active or archived list
2. **Create New Analysis**:
   - Click "Create New Analysis"
   - Upload a discussion guide (.docx file)
   - The system will parse the guide and create analysis sheets
3. **View Existing Analyses**: Browse saved content analyses for the selected project
4. **Work with Analysis Sheets**:
   - Navigate between different sheets/tabs (e.g., Demographics, Key Findings)
   - Each sheet contains columns for different analysis topics
5. **Fill Analysis from Transcripts**:
   - Upload or select transcripts
   - Use "Fill from Transcript" to automatically populate analysis cells with AI-generated insights
6. **Edit Analysis Content**: Click on any cell to edit or refine the AI-generated analysis
7. **View Verbatim Quotes**: Access supporting quotes for each finding
8. **Save Analysis**: Save your work to the project for future reference
9. **Navigate to Storytelling**: Use the "View in Storytelling" button to create reports

**Key Features:**
- AI-powered transcript analysis
- Discussion guide parsing and mapping
- Multi-sheet analysis structure
- Verbatim quote extraction
- Integration with Transcripts and Storytelling tools
- Excel export functionality

---

### Transcripts

**Intended Use:**
Transcripts is a tool for managing, cleaning, and organizing interview transcripts from qualitative research projects. It helps maintain transcript files and link them to content analyses.

**How to Use:**
1. **Select a Project**: Choose a project from the active or archived list
2. **View Project Transcripts**: See all transcripts associated with the selected project
3. **Upload Transcripts**:
   - Click "Upload Transcript"
   - Select a transcript file (.docx)
   - Choose cleaning options (remove timestamps, speaker labels, etc.)
   - Assign respondent numbers
4. **Clean Transcripts**: Use the cleaning feature to remove formatting, timestamps, and standardize the text
5. **Download Transcripts**: Download original or cleaned versions
6. **Link to Content Analysis**: Connect transcripts to content analyses for automated filling
7. **View Transcript Details**: See upload date, respondent information, and associated analyses
8. **Search Transcripts**: Use the search function to find specific content across transcripts

**Key Features:**
- Transcript file management
- Automated cleaning and formatting
- Respondent number assignment
- Integration with Content Analysis
- Download capabilities
- Search functionality

### Storytelling

**Intended Use:**
Storytelling transforms content analysis findings into compelling narratives, reports, and presentations. It helps create key findings summaries, storyboards, and executive reports.

**How to Use:**
1. **Select a Project**: Choose a project from the active or archived list
2. **Select Content Analysis**: Choose which content analysis to use for storytelling
3. **Navigate Tabs**:
   - **Key Findings**: AI-generated summary of main insights
   - **Storyboard**: Visual storyboard creation with slides
   - **Report Outline**: Structured report outline generation
   - **Q&A**: Interactive chat to ask questions about the findings
   - **Quote Finder**: Search and filter verbatim quotes
4. **Generate Key Findings**: Click "Generate Key Findings" to create an AI-powered summary
5. **Create Storyboard**: Build visual presentations with findings and quotes
6. **Ask Questions**: Use the Q&A tab to get answers about specific aspects of the research
7. **Find Quotes**: Search for specific quotes by keyword, theme, or respondent
8. **Export Content**: Copy findings, quotes, and summaries for use in reports

**Key Features:**
- AI-generated key findings
- Interactive storyboard creation
- Report outline generation
- Q&A chat interface
- Quote search and filtering
- Integration with Content Analysis and Transcripts

## Quantitative Tools

### QNR

**Intended Use:**
QNR (Questionnaire) is a tool for uploading, parsing, editing, and managing survey questionnaires. It supports questionnaire parsing, editing, preview, and export to Forsta/Decipher-compatible XML.

**How to Use:**
1. **Select a Project**: Choose a project from the active or archived list
2. **Upload Questionnaire**:
   - Click "Upload Questionnaire"
   - Select a .docx questionnaire file
   - The system will parse questions, question types, and response options
3. **View Questionnaire Structure**:
   - **Variables View**: See all questions organized by section
   - **Banners View**: View banner groups and cuts
   - **Data View**: Upload and view survey data
4. **Edit Questions**:
   - Click on any question to edit
   - Modify question text, response options, and question types
   - Add or remove response options
5. **Filter Questions**: Use filters to view specific question types or sections
6. **Upload Data File**: Upload Excel/CSV data files to link with the questionnaire
7. **Sync with Tabs**: Use "Sync with Tabs" to transfer questionnaire structure to the Tabs tool
8. **Export XML**: Generate Forsta-compatible XML for survey deployment

**Key Features:**
- Automatic questionnaire parsing
- Question type detection (Single Select, Multi Select, Scale, Open End, Grid)
- Question editing and management
- Data file upload and linking
- XML export for survey platforms
- Integration with Tabs tool

---

### Tabs

**Intended Use:**
Tabs is a comprehensive data tabulation tool for creating cross-tabulations, banner tables, and statistical analyses from survey data. It works in conjunction with QNR to create professional data tables.

**How to Use:**
1. **Select a Project**: Choose a project from the active or archived list
2. **Select a Questionnaire**: Choose a questionnaire that has been synced from QNR
3. **View Modes**:
   - **Variables View**: Browse and select variables (questions) to tabulate
   - **Banners View**: Create and manage banner groups (column headers)
   - **Data View**: View raw data and upload data files
4. **Create Banner Groups**:
   - Click "Create Banner Group"
   - Select variables to include as banner cuts
   - Define custom nets and combinations
5. **Build Cross-Tabs**:
   - Select a variable (row) from the variables list
   - Select a banner group (columns)
   - View the generated cross-tabulation table
6. **Customize Tables**:
   - Add custom nets (combinations of response options)
   - Hide or show specific columns
   - Apply filters
7. **View Raw Data**: Access the full dataset for reference
8. **Export Tables**: Copy or export tables for use in reports

**Key Features:**
- Cross-tabulation generation
- Banner group creation and management
- Custom nets and combinations
- Variable filtering and organization
- Raw data viewing
- Integration with QNR tool

### Utilities

**Intended Use:**
Utilities is a tool for managing and visualizing conjoint analysis utility data. It displays average utilities, attribute importance, and helps with conjoint analysis interpretation.

**How to Use:**
1. **Select a Project**: Choose a conjoint project from the active or archived list
2. **Upload Utilities File**: Upload an Excel file containing utility data
3. **View Utilities**:
   - **Utilities Tab**: View average utilities for each attribute level
   - **Importance Tab**: View attribute importance calculations
4. **Adjust Axis Settings**:
   - Choose axis mode (Independent, Consistent, or Manual)
   - Set manual min/max values if using manual mode
5. **Interpret Results**: Analyze utility values to understand attribute preferences
6. **Export Data**: Copy utility tables for use in reports

**Key Features:**
- Utility data visualization
- Attribute importance calculation
- Flexible axis scaling
- Conjoint project integration
- Data export capabilities

---

### Stat Testing

**Intended Use:**
Stat Testing is a tool for performing statistical significance testing on survey data. It helps determine if differences between groups or columns are statistically significant.

**How to Use:**
1. **Set Confidence Level**: Choose 95%, 90%, or 80% confidence level
2. **Enter Column Data**:
   - Add columns (A, B, C, etc.)
   - Enter column titles and sample sizes
   - Input percentage values for each row
3. **Add Rows**: Add as many rows as needed for your analysis
4. **View Results**: The tool automatically calculates and displays:
   - Significant differences (highlighted in color)
   - Which columns are significantly higher or lower
5. **Paste Data**: Copy and paste data from Excel for quick entry
6. **Export Results**: Export the table to Excel/CSV format

**Key Features:**
- Statistical significance testing
- Multiple confidence levels
- Visual highlighting of significant differences
- Excel data import/export
- Support for multiple columns and rows

---

### Open-End Coding

**Intended Use:**
Open-End Coding is an AI-powered tool for coding open-ended survey responses. It automatically generates themes, codes responses, and creates codebooks for qualitative analysis.

**How to Use:**
1. **Upload Data File**: Upload an Excel/CSV file with open-ended responses
   - First column should contain respondent IDs
   - Remaining columns should contain open-ended questions
2. **Process Responses**: Click "Process" to begin AI-powered coding
3. **View Results Tabs**:
   - **Summary**: Overview of themes and frequencies for each question
   - **Codebook**: Detailed codebook with theme descriptions
   - **Raw Codes**: Individual response coding
   - **Combine**: Merge similar themes
4. **Review Themes**: Review AI-generated themes for each question
5. **Edit Codes**: Modify theme names, combine themes, or adjust coding
6. **Export Results**: Export coded data and codebooks

**Key Features:**
- AI-powered theme generation
- Automatic response coding
- Codebook creation
- Theme merging and editing
- Frequency analysis
- Excel/CSV export

### Conjoint Simulator (Admin Only)

**Intended Use:**
Conjoint Simulator is an advanced tool for simulating market scenarios based on conjoint analysis results. It predicts market share and preference for different product configurations.

**How to Use:**
1. **Access from Conjoint Projects**: Navigate to a conjoint project and open the simulator
2. **Load Model**: The simulator loads utilities from the conjoint analysis
3. **Create Scenarios**:
   - Define product configurations by selecting attribute levels
   - Add multiple scenarios to compare
4. **Run Simulation**: Click "Run Simulation" to calculate market shares
5. **View Results**: See predicted market share for each scenario
6. **Adjust Rules**: Choose between "Logit" or "First Choice" simulation rules
7. **Compare Scenarios**: Compare multiple product configurations side-by-side

**Key Features:**
- Market share prediction
- Scenario comparison
- Multiple simulation rules
- Integration with Conjoint Projects
- Visual results display

## Admin Center (Admin Only)

**Intended Use:**
Admin Center is a comprehensive administrative dashboard for managing users, tracking costs, handling feature requests, and monitoring system storage.

**How to Use:**

### User Management Tab
1. **View All Users**: See a list of all registered users
2. **Create New User**: Click "Create User" to add new users
   - Enter name, email, password, role, and company
3. **Edit User Roles**: Change user roles (user, admin, oversight)
4. **Update Company**: Assign users to companies
5. **Reset Passwords**: Change user passwords
6. **Delete Users**: Remove users from the system

### Cost Tracker Tab
1. **View Cost Data**: See AI usage costs organized by project
2. **Filter Projects**: Filter by active or archived projects
3. **Expand Project Details**: Click on a project to see detailed cost breakdown
4. **Monitor Spending**: Track costs for different AI services and features

### Feature Requests Tab
1. **View Requests**: See all submitted feature requests
2. **Filter by Status**: Filter by status (Not Reviewed, Considering, In Progress, Done)
3. **Update Status**: Change the status of feature requests
4. **Add Comments**: Add internal comments and notes
5. **Set Priority**: Assign priority levels to requests

### Bug Reports Tab
1. **View Reports**: See all submitted bug reports
2. **Filter by Status**: Filter by status and severity
3. **Update Status**: Track bug resolution progress
4. **Add Comments**: Document investigation and fixes

### Settings Tab
1. **Reset Project Tasks**: Reset tasks for individual projects or all projects
2. **Select Project**: Choose a project to reset its task list
3. **Bulk Reset**: Reset tasks for all active projects at once

### Storage Tab
1. **View Storage Usage**: See storage usage by project
2. **File Management**: Browse all files in the system
3. **Filter Files**: Filter by category, project, or file type
4. **Delete Files**: Remove unnecessary files
5. **Delete Orphaned Files**: Clean up files not associated with projects
6. **Monitor Disk Space**: View total disk usage and available space

### Messages Tab
1. **View Admin Messages**: See all system-wide messages
2. **Create Messages**: Create new messages to display to users
3. **Edit Messages**: Update existing messages
4. **Activate/Deactivate**: Control which messages are shown to users
5. **Delete Messages**: Remove old messages

**Key Features:**
- Complete user management
- Cost tracking and monitoring
- Feature request and bug report management
- System storage monitoring
- Project task management
- System-wide messaging

## Additional Notes

### Navigation Tips
- The sidebar can be collapsed by clicking the logo in the header
- Active tabs are highlighted in orange (#D14A2D)
- Some tools require a project to be selected before use
- Admin-only features are only visible to users with admin role

### Integration Between Tools
- **QNR → Tabs**: Sync questionnaire structure to create tabulations
- **Content Analysis → Storytelling**: Use analysis findings to create reports
- **Transcripts → Content Analysis**: Fill analysis from transcript data
- **Conjoint Projects → Utilities**: View utility data from conjoint analyses

### Getting Help
- Use the "Report bug" or "Feature request" links at the bottom of the sidebar
- Contact your system administrator for access issues
- Refer to project-specific documentation for detailed workflows
